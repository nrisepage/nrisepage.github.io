시장 다이어그램 시안 비교 (A/B/C)

현재는 X + 점선 원이 "사용자 실패"처럼 읽혀, "시장이 결과만 판매" 메시지와 어긋남. 3가지 방향 비교.

현재 (라이브)

X + 점선 원 → "실패"로 읽힘

결심 → ✕ → 점선 원(목표). 해석이 "사용자가 실패"로 쏠림.

A안 — 빈 경로 (가장 간단)

X 제거 + 점선만 연결, 양쪽 결심·목표 동일 무게

결심·목표는 양쪽 동일, 차이는 사이의 "과정" 유무. "실패" 뉘앙스 없이 "시장은 과정을 못 채워준다"가 자연스럽게 읽힘.

B안 — 직선 점프

결심에서 목표로 화살표 하나, 단계 없음 vs 단계 있음 대비

시장은 결심에서 목표로 "점프 강요", 콰트는 단계적 진행. 대비가 가장 강함.

C안 — 결과만 진열 (메타포 변경)

시장 = 결과를 상품처럼 진열 / 콰트 = 결심→과정→목표 여정

시장은 "다이어트 -10kg / 근육 / 자세교정"같은 결과를 상품처럼 진열, 콰트는 결심에서 그 결과까지 가는 여정을 만듦. 메타포 가장 정확함.
