시장 다이어그램 시안 v4 — 자판기 버리고 "결과+가격"만 남김

진단 (a/c/d): 결과가 안 보임 + 자판기 메타포가 흐림 + 위계 약함. → 컨테이너 chrome 제거하고 결과 워드를 hero로, 가격으로 transaction 시그널, 강한 타입 위계.

G안 — Pure typography (가장 미니멀)

컨테이너 없음 · 결과 워드 크게 · ₩ 핑크 가격으로 transaction

위계: 결과 (26px 검정 굵게) → 가격 (13px 핑크) → 라벨 (11px 회색). 컨테이너 chrome 0%, RIGHT의 미니멀 톤과 완전 매칭. 메시지가 가장 직격.

H안 — Receipt (영수증/주문서)

item + price 리스트 + 합계 라인. transaction이 가장 명시적

영수증 모양(하단 톱니 절취) + RESULT SHOP 헤더 + 항목·가격·합계. transaction이 가장 명시적 ("거래가 일어남"이 한눈에 보임). 결과 항목명도 풀 카피로 더 명확.

I안 — Price tag stickers (가격표 스티커)

결과 워드에 핑크 ₩ 가격표가 매달림. 시장 좌판 가격표 느낌

3개의 가격표가 끈에 매달려 흔들리고 그 아래 결과 워드. "이게 상품이다 / 가격이 있다"가 직관적. 가격표 형태 자체가 "selling" 시그널.
